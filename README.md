# FinLife — Financial Digital Twin

A Kotlin Multiplatform adventure for Android and Desktop, developed for UBS × LauzHack and JetBrains.
Follow Maya, a fictional student in Lausanne, month by month and compare financial choices **from today**.

The app shows available cash, unpaid bills, net worth, budget envelopes and a twelve-month outlook.
What If previews compare an internship, shared housing, both, or no new choice, using the real monthly engine.
There is no historical decision editor.

See [FinLife's developer guide](FinLife/README.md) for setup, financial assumptions, tests and limitations.
